# Tools catalog

Free and open-source (or free to use) security tools, rated for a home lab on an Apple Silicon Mac mini with UTM VMs.

- **Activity** is GitHub stars and last code push, checked 2026-11-22 from the GitHub API. [KNOWN]
- **Mac fit** means: will it run in an ARM Linux VM (or natively) on Apple Silicon? Notes say how we know.
- **Difficulty** is our judgment for someone at Security+ level. [INFERRED]

**Key takeaway:** on your Mac, the winning stack is **Zeek + Suricata + Wazuh + osquery**, plus **Atomic Red Team** to test them. Security Onion is great, but it only supports x86-64, so it won't run on Apple Silicon. [KNOWN: Security Onion docs]

## Start with these five

1. **Wireshark** to see packets (Lab 1).
2. **Nmap** to map your own network (Lab 1).
3. **Wazuh** as your free SIEM (Lab 7).
4. **Zeek + Suricata** as your network sensor (Lab 5).
5. **Atomic Red Team** to check that your sensors actually see attacks (Lab 8).

## A note on licenses

- **Open source (OSI)**: MIT, BSD, Apache, GPL, AGPL, LGPL. Free to use and study. GPL and AGPL have rules if you share modified versions.
- **Source-available**: Elastic License 2.0 lets you read and use the code but limits offering it as a service. It is not OSI open source.
- **NPSL** (Nmap): free for normal use, with extra terms for redistributing it inside commercial products.
- **DRL 1.1** (Sigma rules): free to use, with attribution rules if you share converted rules.

Licenses are as reported by GitHub or the project's LICENSE file on 2026-11-22. Always check the project's current LICENSE before reusing code. [KNOWN]

## The golden rule

Every tool here can be used for harm if pointed at the wrong target. Point them only at your own lab. See [labs/SAFETY.md](../labs/SAFETY.md).

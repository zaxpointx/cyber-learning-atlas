# Technique to defense map

How common attacks work, how to stop them, and how to catch them. Each row pairs a MITRE ATT&CK technique with MITRE D3FEND defenses, the logs that would show it, and a lab where you practice it.

- Technique IDs, names and tactics: **[KNOWN]** from ATT&CK Enterprise v20.1 (checked 2026-11-22).
- D3FEND picks and the "what to log" column: **[INFERRED]**, our own pairing from the D3FEND catalog. They are good starting points, not the only answers.
- Example incidents link to [incidents/](../incidents/README.md).

> Heads-up for older study guides: ATT&CK v20 renamed the old **Defense Evasion** tactic (TA0005) to **Stealth** and added a new **Defense Impairment** tactic (TA0112). Some older IDs, like T1562 Impair Defenses, were revoked and replaced. [KNOWN: ATT&CK v20.1 STIX data]

## How to read a row

1. **Technique**: what the attacker does (click the ID for MITRE's page).
2. **Plain words**: the same thing, simply.
3. **Defend (D3FEND)**: the defensive techniques that make it harder.
4. **Detect**: what logs or tools would show it happening.
5. **Practice**: the lab where you see it with your own eyes.

## Where to go deeper

- **ATT&CK website:** https://attack.mitre.org/ (the matrix, groups, software and data sources).
- **ATT&CK raw data:** https://github.com/mitre-attack/attack-stix-data (good for scripts).
- **ATT&CK for ICS:** https://attack.mitre.org/matrices/ics/ (industrial and grid attacks, the kind ORNL studies).
- **D3FEND:** https://d3fend.mitre.org/ (click any defense to see which attacks it counters).
- **CISA advisories** now usually include an ATT&CK table and, in recent ones, a D3FEND table. The [Salt Typhoon advisory](https://www.cisa.gov/news-events/cybersecurity-advisories/aa25-239a) has a router-hardening D3FEND table worth reading next to [Lab 2](../labs/02-harden-your-cisco-router.md).

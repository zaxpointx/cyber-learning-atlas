# Lab write-up template

Copy this into a new file (for example `writeups/lab-05.md` in your own portfolio repo) after each lab. Keep it to one or two pages. Write it in your own words.

```markdown
# Lab NN: <title>

**Date:** YYYY-MM-DD
**Time spent:** X hours
**Environment:** Mac mini + UTM, VMs: <names and OS>, network: <host-only subnet>

## Goal
One or two sentences.

## What I set up
Bullet list. Include versions (for example "Suricata 7.0.10").

## What I did
Numbered steps, with the important commands in code blocks.

## What I saw
Screenshots or log snippets (remove anything private).

## ATT&CK and D3FEND
- Techniques I simulated or watched for: T____ <name>
- Defenses I used: D3-___ <name>

## What surprised me / what broke
The honest part. This is what interviewers love.

## If I did it again
One or two improvements.

## Security+ / Network+ link
Which exam objective this practiced.
```

**Tip:** a folder of these write-ups on GitHub is a better resume line than "familiar with Wireshark". [INFERRED]

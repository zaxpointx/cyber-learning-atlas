# Practice platforms

Legal places to practice hacking and defending. These are the **only** places outside your own lab where attacking things is allowed, and only within each platform's rules.

- Cost and level are as shown on each site's public pages on 2026-11-22. Prices change, so check before paying. [KNOWN for the free/paid split, INFERRED for level]
- Signing up is your call. Agents working on this repo don't create accounts for you.

**Key takeaway:** start with **OverTheWire Bandit** (Linux basics, no account), then **CyLab Security Academy (formerly picoCTF)** for CTF puzzles, then pick one of **TryHackMe** or **Hack The Box** and stick with it. For the blue team side, **Blue Team Labs Online** and **CyberDefenders** are the closest to real SOC work.

## Rules that still apply

- Only attack the targets each platform gives you, using their VPN or browser machine.
- Don't share flags or full solutions for live competitions.
- Write-ups for retired boxes and old challenges are fine and make great portfolio pieces.
